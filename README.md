# SOLLUX Landing Page 

## Goal

The goal of this project is to complete a recruitment coding assignment focused on building a landing page from a Figma design using a clean vanilla frontend stack, accurately reproducing the layout structure, visual styling, interactive elements, and background gradient animation.

## Languages & Technologies

* **HTML5** 
* **CSS3**
* **JavaScript (Vanilla JS)**

## How to open
Open `index.html` in any web browser on any OS (or use a local server if needed).
